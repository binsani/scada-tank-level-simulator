# Contributing

Thanks for your interest in improving the Tank Level SCADA Simulator. Contributions from learners, engineers and developers are welcome.

## Getting started

1. Read the README and follow the local setup instructions.
2. Search existing issues and pull requests before starting substantial work.
3. Open an issue to discuss significant changes or new features.
4. Fork the repository and create a focused feature branch.
5. Make your changes, adding tests and documentation where applicable.
6. Run `php artisan test` and `npm run build` if the project dependencies and environment support them. Mention any checks you could not run.
7. Open a pull request explaining what changed, why, and how you tested it.

## Reporting bugs

Include reproduction steps, expected and actual behavior, environment details, and relevant logs with secrets removed.

## Security

Do not publish credentials, personal data, or exploitable security details in public issues. Contact the maintainer privately through an appropriate GitHub channel to coordinate responsible disclosure.

## Project scope

This is a simulation and educational reference, not a certified industrial control or safety system. Do not connect it to live industrial equipment without independent engineering review and appropriate safeguards.

## Community standards

Be respectful, constructive, and welcoming to contributors of all experience levels.
